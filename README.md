# 2D Endless Runner – Computer Graphics Sessional

## Project

A simple interactive 2D Endless Runner built with **Python + PyOpenGL + GLUT**.

## Career Track

**Track C – Game / Graphics Industry or Freelancing**

## Implemented Computer Graphics Techniques

1. Line & Shape Drawing
2. 2D Transformations
3. Color Fill
4. Line Clipping using Cohen-Sutherland
5. Cubic Bezier Curves

## Features

- Jump
- Duck
- Gravity and jump physics
- Random obstacles
- Collision detection
- Score and high score
- Increasing game speed
- Pause / restart / game over
- Moving clouds
- Dust particles

## Controls

| Key | Action |
|---|---|
| SPACE / UP | Jump |
| DOWN | Duck |
| P | Pause / Resume |
| R | Restart |
| ESC | Exit |
